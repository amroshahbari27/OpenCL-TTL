24/*
25 * TTL_LOOP_*D's last two arguments before the body are bare, unlabeled
26 * parenthesized tensor-name lists -- e.g. `(C), (A, B), { ... }` -- which
27 * reads fine once you already know the convention but says nothing at the
28 * call site about which list is which. These two macros are the standing,
29 * canonical way to name that convention instead of leaving it implicit:
30 * wrap each list in the one that matches its role. Both simply forward
31 * their arguments unchanged in parentheses -- there is no new parsing,
32 * behavior, or attribute; TTL_LOOP_*D sees an identical token stream
33 * either way. Language-independent (no #ifdef __cplusplus split needed):
34 * pure textual substitution, defined once, used by both the C and C++
35 * TTL_LOOP_*D forms below.
36 *
37 * TTL_LOOP_3D(i, 0, M, 64, j, 0, N, 64, k, 0, K, 64,
38 * TTL_PROMOTE_ONLY(C),
39 * TTL_PROMOTE_AND_DOUBLE_BUFFER(A, B), {
40 * ...
41 * })
42 */
